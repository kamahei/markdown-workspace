Markdown Workspace

Read Markdown files in Chrome — and whole folders of them, with a file browser built in.

Source on GitHub Privacy policy

Not yet on the Chrome Web Store. Until it is, build it from source — the steps are in the repository's README.

What it does

Drop a .md file onto Chrome and it renders. Drop a folder and you get a sidebar file tree, with links between documents that actually work — so a docs/ directory reads like a small site, with no build step.

  • Syntax highlighting, LaTeX math, and Mermaid diagrams.
  • Light, dark, and system themes.
  • Usable without a mouse: arrow through the tree, Enter to open, / to filter.
  • CJK-aware — Japanese, Chinese and Korean text renders without the spurious space a wrapped line would otherwise gain.

Your files stay on your device

There is no server, no analytics, and no telemetry. Documents are read, converted to HTML, and displayed, all inside your own browser. Manifest V3 forbids remote code, so every rendering library ships inside the extension package — and the build is checked for that on every commit.

Markdown on websites is ignored unless you add the site yourself in settings. Nothing is enabled by default. The full statement is in the privacy policy.

One thing Chrome makes you do yourself

Chrome blocks extensions from reading local files until you allow it, and an extension cannot turn that on for you. After installing, open chrome://extensions, find Markdown Workspace, click Details, and enable Allow access to file URLs. The extension shows a setup page that walks through this and tells you when it has taken effect.

Reporting something

Bugs and ideas go to GitHub issues. For anything security-related, please use private reporting rather than a public issue — the security policy explains how.
