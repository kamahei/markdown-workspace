# Markdown Workspace

You are reading this file through the extension. The sidebar on the left is
showing the folder it lives in — that is the part most Markdown viewers leave
out.

Try clicking around:

- [Getting started](docs/getting-started.md) — the one setup step Chrome requires
- [Writing](docs/writing.md) — tables, task lists, footnotes and quotes
- [Code and diagrams](docs/code-and-diagrams.md) — highlighting, math, Mermaid
- [Reference](docs/reference/shortcuts.md) — keyboard shortcuts

Every link above is a **relative link**. They resolve against this file and
open in place, so a folder of documents reads like a small site.

## What makes this different

|                         | Single-file viewer | Markdown Workspace            |
| ----------------------- | ------------------ | ----------------------------- |
| Open one `.md` file     | Yes                | Yes                           |
| Open a **folder**       | No                 | Yes                           |
| Links between documents | Usually broken     | Resolve and navigate          |
| Sidebar file tree       | No                 | Yes                           |
| Where your files go     | —                  | Nowhere. Everything is local. |

## Three ways in

1. Drag a `.md` file onto Chrome.
2. Drag a **folder** onto Chrome — including this one.
3. Click the toolbar icon to open the workspace, then drop a folder on it.

> Nothing here is uploaded. There is no server to upload it to.
