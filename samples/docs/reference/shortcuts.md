# Keyboard shortcuts

Everything is reachable without a pointer.

| Shortcut                     | Action                      |
| ---------------------------- | --------------------------- |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | Toggle the sidebar          |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Focus the file filter       |
| <kbd>Ctrl</kbd>+<kbd>\</kbd> | Toggle raw / rendered       |
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | Close the active tab        |
| <kbd>↑</kbd> <kbd>↓</kbd>    | Move through the file tree  |
| <kbd>→</kbd> <kbd>←</kbd>    | Expand or collapse a folder |
| <kbd>Enter</kbd>             | Open the selected file      |
| <kbd>Esc</kbd>               | Clear the filter            |

## In the tree

The file tree is a single tab stop. Once it has focus, the arrow keys move
within it — the standard pattern for a tree, and the reason tabbing does not
walk through five thousand rows one at a time.
