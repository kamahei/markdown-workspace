# はじめに

設定はひとつだけ、そしてそれは拡張機能側では代行できない唯一の項目です。

## ローカルファイルへのアクセスを許可する

Chrome は、許可するまで拡張機能が `file://` ページを読むことを禁止しています。
拡張機能はこの権限を要求することも、ダイアログを出すことも、許可画面を開く
ことすらできません。結果を検出できるだけです。

1. `chrome://extensions` を開く
2. **Markdown Workspace** を探して**詳細**をクリック
3. **ファイルの URL へのアクセスを許可する**をオンにする

インストール直後の設定ページを閉じてしまった場合は、**設定**から再度開けます。

## そのあとは

フォルダを開いて読み始めるだけです。[ツアーに戻る](../README.md)。

## ウェブ上の Markdown

`http(s)` 配信の Markdown は、設定でそのサイトを自分で追加しない限り無視され
ます。既定では何も有効になっていません。

これは見た目以上に重要です。サーバーが `Content-Type: text/markdown` を返すと
Chrome はファイルをダウンロードしてしまい、拡張機能が処理できるページ自体が
存在しなくなります。オリジンを追加すると、そのサイトに限ってこのヘッダーを
訂正できるようになります。
