# キーボードショートカット

すべての操作がポインタなしで到達できます。

| ショートカット                      | 動作                                       |
| ----------------------------------- | ------------------------------------------ |
| <kbd>Ctrl</kbd>+<kbd>B</kbd>        | サイドバーの表示切替                       |
| <kbd>Ctrl</kbd>+<kbd>&#92;</kbd>    | ソース／描画の切替                         |
| <kbd>/</kbd>                        | ファイル絞り込みにフォーカス               |
| <kbd>Alt</kbd>+<kbd>W</kbd>         | アクティブなタブを閉じる（ワークスペース） |
| <kbd>Esc</kbd>                      | 絞り込みを解除                             |
| <kbd>&uarr;</kbd> <kbd>&darr;</kbd> | ファイルツリー内を移動                     |
| <kbd>&rarr;</kbd>                   | フォルダを開く、または中に入る             |
| <kbd>&larr;</kbd>                   | 閉じる、または親フォルダへ戻る             |
| <kbd>Enter</kbd>                    | 選択中のファイルを開く                     |
| <kbd>Home</kbd> <kbd>End</kbd>      | 先頭／末尾のファイルへ                     |

macOS では <kbd>Ctrl</kbd> の代わりに <kbd>Cmd</kbd> を使います。

## Ctrl+P と Ctrl+W を使わない理由

どちらも Chrome が握っており、拡張機能側で奪い返すことはできません。

<kbd>Ctrl</kbd>+<kbd>W</kbd> はタブを閉じる**予約済み**のキーで、Chrome は
ページに一切渡しません。どう書いても拡張機能から割り当てられません。
<kbd>Ctrl</kbd>+<kbd>P</kbd> は印刷ダイアログです。技術的には打ち消せますが、
読んでいるドキュメントから印刷を奪うのは行儀が悪い挙動です。
<kbd>Ctrl</kbd>+<kbd>1</kbd>〜<kbd>9</kbd> のタブ切替も同様に予約済みです。

そのため絞り込みは修飾なしの <kbd>/</kbd>（多くの閲覧ツールで共通の慣習）、
タブを閉じるのは <kbd>Alt</kbd>+<kbd>W</kbd> にしています。

## ツリー内での操作

ファイルツリーはタブ停止位置がひとつだけです。フォーカスが入ったあとは矢印
キーで内部を移動します — ツリーの標準的な操作方法であり、5,000 行を1つずつ
タブで辿らずに済む理由でもあります。ツリーにフォーカスがある間、現在の行は
枠線で示されます。

<kbd>&rarr;</kbd> と <kbd>&larr;</kbd> はリストの上下ではなく、フォルダ構造を
辿ります。フォルダ上で <kbd>&rarr;</kbd> を押すと開き、もう一度押すと中に入ります。
ファイル上では何も起きません—開くべき中身がないからです。<kbd>&larr;</kbd> は
開いているフォルダを閉じ、それ以外のときは現在位置を含む親フォルダへ移ります。
階層を登るのに使います。

## ツリーに入る

フォルダをブラウザにドロップした直後は、すでにツリーにフォーカスがあります。
そのページ自体がファイル一覧なので、矢印キーがそのまま使えます。

ツリーからドキュメントを開いてもフォーカスはツリーに残るので、マウスに手を
伸ばさずに矢印と <kbd>Enter</kbd> を繰り返せます。本文に戻るときは <kbd>Esc</kbd> を
押します—フォーカスが本文に戻り、<kbd>Space</kbd> や <kbd>PageDown</kbd> で再び
スクロールできます。

絞り込み欄からは <kbd>&darr;</kbd> でリストに降りられます。<kbd>/</kbd> だけで完結する
導線になっています：<kbd>/</kbd>、数文字入力、<kbd>&darr;</kbd>、<kbd>Enter</kbd>。
