# キーボードショートカット

すべての操作がポインタなしで到達できます。

| ショートカット               | 動作                         |
| ---------------------------- | ---------------------------- |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | サイドバーの表示切替         |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | ファイル絞り込みにフォーカス |
| <kbd>Ctrl</kbd>+<kbd>\</kbd> | ソース／描画の切替           |
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | アクティブなタブを閉じる     |
| <kbd>↑</kbd> <kbd>↓</kbd>    | ファイルツリー内を移動       |
| <kbd>→</kbd> <kbd>←</kbd>    | フォルダの展開・折りたたみ   |
| <kbd>Enter</kbd>             | 選択中のファイルを開く       |
| <kbd>Esc</kbd>               | 絞り込みを解除               |

## ツリー内での操作

ファイルツリーはタブ停止位置がひとつだけです。フォーカスが入ったあとは矢印
キーで内部を移動します — ツリーの標準的な操作方法であり、5,000 行を1つずつ
タブで辿らずに済む理由でもあります。
