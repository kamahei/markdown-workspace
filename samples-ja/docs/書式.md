# 書式

CommonMark に加えて、実際に使われている GitHub 拡張に対応しています。

## テキスト

通常のテキスト、**太字**、_斜体_、~~取り消し線~~、`インラインコード`、
そして[リファレンスへのリンク](リファレンス/ショートカット.md)。

URL の自動リンクも効きます: https://example.com

## リスト

- ネストしたリストは
  - インデントを保ちます
    - 必要なだけ深く
- 番号付きリスト:

1. 一番目
2. 二番目
3. 三番目

## タスクリスト

- [x] Markdown を描画する
- [x] フォルダを閲覧する
- [x] 相対リンクを解決する
- [ ] 心を読む

## 表

| 機能                   | 読み込まれる条件         |     サイズ |
| ---------------------- | ------------------------ | ---------: |
| Markdown コア          | 常時                     |   約 86 KB |
| シンタックスハイライト | コードブロックがある時   | 必要時のみ |
| 数式                   | `$...$` がある時         | 必要時のみ |
| 図                     | Mermaid ブロックがある時 | 必要時のみ |

## 引用と脚注

> Markdown のフォルダは、誰も構築していない小さなウェブサイトです。

脚注も期待どおり動きます[^なぜ]。

[^なぜ]: 参照元へ戻るリンクも付きます。

## 定義リスト

ワークスペース
: タブとフォルダツリーを備えた拡張機能のページ。

リーダー
: 単一ファイルを直接開いたときの表示。

## アラート

GitHub の5種類のコールアウトは、ここでも同じように表示されます。GitHub 向けに
書かれた `docs/` フォルダが、ディスクから読んだときに違って見えないように、
というのが目的です。

> [!NOTE]
> 知っておくと便利ですが、読み飛ばしても困りません。

> [!TIP]
> <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>F</kbd> で、フォルダ内のすべての
> 文書をまとめて検索できます。

> [!IMPORTANT]
> Chrome は、許可するまで拡張機能がローカルファイルを読むことを認めません。

> [!WARNING]
> `pnpm build` は `.output/` の中身を上書きします。

> [!CAUTION]
> 設定のリセットは、記憶しているフォルダとその再オープン権限をすべて消します。

同じ形でも、定義されていない種別はそのまま引用として表示されます:

> [!NOPE]
> 未定義の記法は、勝手に解釈せずそのままにします。

## 絵文字

ショートコードも描画されます。`:tada:` は :tada: になり、:rocket: :sparkles:
:bug: が並んだリリースノートも書いたとおりに読めます。
