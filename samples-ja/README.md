# Markdown Workspace

このファイルは拡張機能を通して表示されています。左のサイドバーには、この
ファイルが入っているフォルダが表示されています — ほとんどの Markdown
ビューワーが省略している部分です。

リンクをたどってみてください:

- [はじめに](docs/はじめに.md) — Chrome が要求する唯一の設定手順
- [書式](docs/書式.md) — 表、タスクリスト、脚注、引用
- [コードと図](docs/コードと図.md) — ハイライト、数式、Mermaid
- [リファレンス](docs/リファレンス/ショートカット.md) — キーボード操作

上のリンクはすべて**相対リンク**です。このファイルを基準に解決され、その場で
開くので、フォルダ全体が小さなサイトのように読めます。

## 何が違うのか

|                            | 単一ファイル型ビューワー | Markdown Workspace     |
| -------------------------- | ------------------------ | ---------------------- |
| `.md` を1つ開く            | できる                   | できる                 |
| **フォルダ**を開く         | できない                 | できる                 |
| ドキュメント間のリンク     | 大抵は切れる             | 解決して移動できる     |
| サイドバーのファイルツリー | なし                     | あり                   |
| ファイルの行き先           | —                        | どこにも送信されません |

## 3つの開き方

1. `.md` ファイルを Chrome にドラッグ＆ドロップする
2. **フォルダ**を Chrome にドラッグ＆ドロップする（このフォルダでどうぞ）
3. ツールバーのアイコンからワークスペースを開き、フォルダをドロップする

> ここにあるものは何もアップロードされません。送信先そのものが存在しません。
